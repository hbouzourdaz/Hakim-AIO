# Hakim PC Care AIO — Landing Page

## النشر على Vercel
1. ضع `index.html` وملف `run.bat` النهائي داخل مجلد `public`.
2. انشر المجلد/المشروع على Vercel كـ Static Site.
3. زر التحميل مرتبط بـ `/run.bat`.

## ملاحظة
هذه صفحة هبوط فقط؛ لا تحتوي على البرنامج نفسه. أضف نسخة `run.bat` التي تريد توزيعها إلى مجلد `public` قبل النشر، وتأكد من أنها تشير إلى الملفات المطلوبة أو أنها حزمة مستقلة فعلاً.
